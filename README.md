# Три уровня — интерактивное резюме

Сайт-игра о профессиональном пути в маркетинге: школа → бакалавриат → своё дело.
Учебный проект-портфолио для поступления в магистратуру НИУ ВШЭ.

## Как открыть

Двойной клик по `index.html` — этого достаточно. Сборка, установка и сервер не нужны:
всё на обычном HTML, CSS и JavaScript, шрифты и спрайты лежат рядом в `assets/`.

Если хочется проверить как «настоящий сайт»:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

Для публикации подойдёт любой статический хостинг — GitHub Pages, Netlify, Vercel:
достаточно залить папку целиком.

## Интро

При загрузке играет сцена ~6 секунд: фотография в рамке проявляется, ступенями
пикселизуется до крупных блоков, вспышка — и на её месте пиксельный персонаж,
который падает в кадр и приземляется уже на титульном экране. Пропускается
кнопкой «Пропустить», любой клавишей или тапом.

Пикселизация считается вживую: фото рисуется в маленький буферный канвас и
растягивается обратно без сглаживания. Пиксели не читаются, поэтому сцена
работает и при открытии с `file://`.

Титульный экран прозрачный (`.screen--clear`) — фон и персонажа под ним рисует
канвас, поэтому упавший персонаж остаётся ровно там, где приземлился.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Идти | `←` `→` или `A` `D` | кнопки внизу экрана |
| Прыжок | `Пробел`, `↑` или `W` | кнопка `↑` |
| Листать реплики | `Enter` или клик по панели | тап по панели |

Проиграть нельзя: после столкновения персонаж возвращается к последнему чекпоинту.
Прохождение — около 9–10 минут.

## Как пересобрать ассеты

Портрет для интро:

```
sips -c 3800 2800 _DSC1251.jpg --out /tmp/crop.jpg
sips -Z 560 -s format jpeg -s formatOptions 72 /tmp/crop.jpg --out assets/photo.jpg
```

Книга Котлера (обложка отделяется от стола по цвету, палитра сводится к семи
цветам дизайн-системы, добавляется контур):

```
sips -c 680 1270 книга.jpg --out /tmp/bc.png -s format png
sips -z 39 72 /tmp/bc.png --out /tmp/bs.png
python3 tools/prep_book.py /tmp/bs.png
```

Предмет получает свою картинку через поле `sprite` в `ITEMS` (`js/content.js`).

## Проверка без браузера

Браузера для автопроверки в системе нет, поэтому игра прогоняется в
JavaScriptCore через заглушку DOM. Запускать из корня проекта.

Полный прогон — интро, три уровня, финал. Бот прыгает, когда впереди
препятствие, поэтому заодно проверяется проходимость геометрии:

```
osascript -l JavaScript tools/headless/play.js
osascript -l JavaScript -e 'var PICK=1' -e "$(cat tools/headless/play.js)"   # другая ветка развилки
```

Снимок кадра уровня — записывает вызовы канваса и рисует их в картинку
`tools/headless/frame.png`. Так видно композицию, не открывая браузер:

```
python3 tools/headless/raster.py --sizes                                     # один раз после новых спрайтов
osascript -l JavaScript -e 'var LVL=1, ATX=2650' -e "$(cat tools/headless/shot.js)"
python3 tools/headless/raster.py
```

`LVL` — уровень с нуля (`-1` для титульного экрана), `ATX` — где поставить
персонажа. Текст рисуется серой плашкой примерной ширины: важно видеть, куда
попадает подпись, а не как она набрана.

## Мобильная версия

На телефоне игра занимает весь экран: ни полей, ни рамки, ни подвала. Экран
делится примерно пополам — верхние 55% это сцена, нижние 45% тёмный пол, на
котором лежат реплика и кнопки, каждый на своём месте и без наложений.

`Engine.resize()` подгоняет канвас под рамку и поднимает линию земли на 55%
высоты. Мир при этом приближается: по ширине показывается 480 единиц вместо
960, иначе персонаж выходил нечитаемо мелким.

Координаты мира не меняются: земля всегда на `GROUND_Y = 430`, высота тёмной
полосы считается от неё до низа кадра, а лишняя высота уходит вверх — в потолок
или небо. Поэтому у уровней в помещении есть цвет `ceiling`: без него верх кадра
был бы пустой стеной.

Пометка об учебных целях на телефоне остаётся на первом экране
(`.foot__note--inline`), а общий подвал скрыт.

## Цвет уровней

У каждого уровня свой блок `palette` в `js/content.js` — цвета сняты с фотографий
в корне проекта: школьный коридор, атриум Плехановки, корпус Высшей школы бизнеса.
`air` красит воздух над землёй, `floor` — тонкую полосу покрытия поверх тёмной
земли, остальные ключи разбирают декорации в `deco()` (`js/engine.js`).

Цвета намеренно приглушены: самым контрастным пятном в кадре должен оставаться
тёмный силуэт персонажа. Все подписи в мире — акцентным оранжевым, иначе на
цветном фоне они теряются.

## Как править тексты

Всё в `js/content.js`, движок трогать не нужно.

```js
{ t: 'Обычная реплика Ангелины' }
{ who: 'Система', t: 'Реплика от другого лица' }
{ ask: 'Вопрос?', opts: [{ label: 'Вариант', then: [ /* реплики */ ] }] }
{ give: 'kotler' }        // выдать предмет из ITEMS
{ act: 'open:budget' }    // команда движку
```

Внутри текста доступны `<b>…</b>` для акцента и `<span class="num">…</span>` для цифр,
латиницы и знака ₽.

## Два ограничения шрифтов

Их важно помнить при правках:

- **в Chava нет знака ₽** — суммы всегда набираются Bricolage через `class="num"`;
- **в Bricolage нет кириллицы вообще** — в него не должно попасть ни одной русской
  буквы. Он только для цифр, латиницы (`NPV`, `LTV`) и ₽.

Подписи на канвасе выбирают шрифт автоматически: `labelFont()` в `js/engine.js`
смотрит, есть ли в строке кириллица.

## Геометрия уровней

Физика подобрана под карты: высота прыжка ≈ 156 px, дальность ≈ 193 px.
При добавлении препятствий нужно держаться этих чисел:

- платформы — не выше 156 px над точкой отталкивания;
- разрывы в земле (`pit`) — не шире 100 px;
- висящие платформы — низ не ниже `GROUND_Y - 114`, иначе персонаж упирается в них головой;
- проиграть в игре нельзя, поэтому непроходимых мест быть не должно.

## Спрайты

Исходники в `персонаж/` — 1254×1254 с большими прозрачными полями.
`tools/prep_sprites.py` обрезает их по альфа-каналу, уменьшает до нативной сетки
и считает якорь «под ступнями», чтобы кадры бега и прыжка не дёргались по горизонтали.
Скрипт работает на чистом Python, без сторонних библиотек:

```
python3 tools/prep_sprites.py
```

Обрезка сделана заранее намеренно: чтение пикселей с `file://` помечает canvas как
tainted, и `getImageData` в браузере падает.
